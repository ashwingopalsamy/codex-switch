# Code of Conduct

CodexSwitch follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) version 2.1.

We expect participants to be respectful, constructive, inclusive, and accountable. Harassment, discrimination, threats, doxxing, sexualized conduct, and intentional disruption are not acceptable in project spaces.

## Reporting

For a conduct concern, contact the maintainer privately through the GitHub profile for [@ashwingopalsamy](https://github.com/ashwingopalsamy). Do not post private details in a public issue or pull request. Reports will be reviewed privately and handled with care.

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when necessary to protect a welcoming and productive project.
