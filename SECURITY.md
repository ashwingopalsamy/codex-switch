# Security policy

Please do not report a vulnerability in a public issue. A report may contain sensitive information about local profile roots, process evidence, authentication flows, or packaged application behavior.

## Supported versions

The default branch is the supported development line. A release or commit is supported only when its documentation and verification evidence identify it as such. Compatibility with a particular ChatGPT version is a separate human validation result and is not implied by the repository version.

## Reporting a vulnerability

Use the repository's private [GitHub Security Advisory reporting page](https://github.com/ashwingopalsamy/codex-switcher/security/advisories/new) when private vulnerability reporting is available. If GitHub does not offer that route, contact [@ashwingopalsamy](https://github.com/ashwingopalsamy) privately and request a secure channel before sharing details.

Include:

- a short description and impact;
- the smallest reproducible case;
- affected commit, app build, macOS version, and ChatGPT version;
- sanitized logs or a minimal fixture;
- any proposed mitigation.

Never include tokens, cookies, authentication URLs, identity hashes, account emails, private conversations, or unredacted profile data. Do not test against another person's account or disclose a vulnerability before a fix is coordinated.
